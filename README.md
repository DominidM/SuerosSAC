# 💉 Landing Page — Sueros Médicos

Landing page profesional para una empresa distribuidora de sueros médicos, construida con Angular + PrimeNG.

---

## 🛠️ Stack Tecnológico

| Herramienta | Versión | Notas |
|---|---|---|
| Angular CLI | 21.1.3 | Framework principal |
| PrimeNG | última estable | Librería de componentes UI |
| @primeng/themes | última estable | Sistema de temas (Aura) |
| PrimeIcons | última estable | Iconografía |
| SCSS | nativo Angular | Preprocesador de estilos |
| Signals | Angular 16+ | Gestión reactiva del estado |
